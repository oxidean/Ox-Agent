# Ox-Agent brainstorming

Use the work-item context packet and produce a compact, evidence-linked analysis.

## Process

1. Identify the problem, constraints, non-goals, and unknowns.
2. Generate at least two materially different approaches.
3. Compare trade-offs, risks, reversibility, and operational impact.
4. Run a short pre-mortem and identify disagreements.
5. Recommend a direction without silently discarding alternatives.
6. Write the structured result using the declared output schema.

Do not modify application source code. Promote accepted technical decisions into an ADR through the ADR skill.
